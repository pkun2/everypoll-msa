# 군집 분석 ETL 명세서 (Cluster Analytics ETL)

개인정보 보호를 위해 "사용자 A"의 개별 투표 이력이 아닌, 통계적으로 유의미한 **군집(Cluster)의 성향**을 텍스트 팩트로 추출하여 RAG에 활용합니다.

## 1. 대상 데이터
- `poll-mysql`: 투표 제목, 카테고리, 태그
- `vote-mysql`: 투표 선택 항목, 유저 정보(나이대, 성별 - 비식별화됨)

## 2. 추출 로직 (Daily Batch)

### A. 군집 정의
- **기본 군집**: `[연령대] + [성별] + [투표 카테고리]`
- 예: "20대 여성 - 뷰티/패션", "40대 남성 - 부동산/경제"

### B. 팩트 가공 (Prompt Engineering용)
- 특정 군집의 투표 응답 비율을 문장화합니다.
- 예시 팩트:
  > "부동산 관련 투표에서 30대 남성 군집은 '전세보다는 자가 구매를 선호한다'는 항목에 75%의 높은 찬성률을 보임."
  > "MBTI 투표에서 10대 유저들은 'E 성향'보다 'I 성향' 선택지에 20% 더 많이 투표함."

## 3. 전송 방식
- **Batch Script (Python)**: 매일 새벽 3시, MySQL Read-only Replica에 접근하여 집계 쿼리 실행.
- **RAG Injection**: 집계된 문장들을 `type: cluster_fact` 메타데이터와 함께 `rag-agent`의 `/api/v1/documents` 엔드포인트로 전송하여 인덱싱.

## 4. 기대 효과
- **개인정보 침해 제로**: 개별 유저의 특정 선택 결과를 저장하지 않음.
- **데이터 효율성**: 수천만 건의 투표 이력 대신 수백 건의 요약된 통계 팩트만 저장하여 검색 속도 향상.
- **인사이트 제공**: "요즘 20대는 어떤 생각을 하나요?"와 같은 추상적 질문에 대해 통계 기반의 정확한 답변 가능.
